# Learning Support Provider Directory

A React-based web application that helps parents find learning support providers for children with learning difficulties. This project is part of Habot Connect DMCC's platform.

## Features

- Browse a list of learning support providers
- Search and filter providers by name or specialization
- View detailed information about each provider
- Responsive design for all screen sizes
- Modern UI with smooth transitions

## Tech Stack

- React
- React Router for navigation
- Tailwind CSS for styling
- Vite for build tooling

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
cd learning-support-directory
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to `http://localhost:5173`
